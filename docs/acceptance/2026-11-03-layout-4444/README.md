# 截图 4444 与常用指令备注间距回归

分支 `dev`。实际查看的桌面文件为 `4444.jpg`（用户称 444.jpeg）。复现采用临时 userData、合成指令与窗口数据、mock keychain，不读取或修改实际工作区、录音或密钥；未打包、未替换安装版。

## 已核实的问题

修复前的 [截图](before/standard-edit-error.png) 和 [实际边界](before/standard-edit-error.json) 同时记录：

- 三条带备注指令的相邻行间距为 `0 / 0 px`。`experience.css` 将 flex 列表覆盖成 `display:block!important`，使原有 `gap` 失效。
- 标准档旧自定义布局面积覆盖约 `83.33%`，录音卡片位于逻辑第 2 行，周围留空。上一轮只补齐了较小档的显示布局。
- 错误提示出现后可用内容高度只有 `457px`，首页仍被最小高度规则撑到 `540px`，下方卡片会被遮挡。
- 编辑按钮悬浮在右上角，覆盖 AI 卡片标题；较短卡片内的 SVG 还会进入时间栏。

## 修复

- 恢复指令 flex 列表和既有 5px 间距，禁止条目被 flex 压缩；保留备注编辑、复制内容与卡片内滚动。
- 标准档有空洞时也使用显示空间分配，已经占满 48 单位的标准布局保持精确原点。尺寸、顺序和存储位置不会因为显示补齐而被改写；调整卡片或换位不再自动扩张兄弟尺寸来填画布。
- 保留首页添加收件箱占位入口，并将其作为显示占位分配，点击仍进入设置。
- 编辑按钮独立成行；错误提示出现、或从其它页面返回时，首页仅使用提示条上方的真实空间，禁止首页外滚。
- 约束图表高度并保留与时间栏的间隔；外层布局规则优先于音乐组件的旧 stretch 规则，避免整页重叠。
