# 淡风透明度微调

在用户认可的扁平淡风版本上，仅将每片风的透明度乘以 1.15。形状、数量、速度、起伏、局部形变与消散参数均沿用该版本。

2026-10-26，macOS Electron，隔离用户目录和固定天气响应。日期与天气为测试数据。`wind.gif` / `wind-strong.gif` 分别为普通风、大风各 48 张连续截图，缩至逻辑像素尺寸；`*-frame.png` 为第 21 帧原始截图，无亮度或对比度增强。

验证：相关天气与日出日落 28 项测试通过；Electron 天气回归通过，覆盖四尺寸、十语言、全部天气族、开关和动画暂停恢复，录帧动图见本目录。语法检查与 `git diff --check` 通过。Windows 真机和安装测试未做。
