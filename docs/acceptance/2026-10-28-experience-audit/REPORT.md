# Pome Panel 用户体验审查

审查时间：2026-10-28 晚至 2026-10-29，Asia/Shanghai。对象：当前 `dev` 工作区，包含尚未提交的提醒可靠性修复。本轮只新增审查材料，没有修改产品功能、样式、版本或真实配置。

完整截图按操作顺序见 [截图与步骤索引](gallery.html)。操作事实另见 [录音及网址检查](operation-observations.json)、[Esc 检查](escape-observations.json)、[动效采样](motion-observations.json) 和 [恢复确认内容](native-confirm-payload.json)。截图全部来自本轮 Electron 运行，样例内容不是用户资料。

## 判断与优先顺序

目前最值得投入的不是增加更多装饰动画，而是：先让核心操作始终可达，再把保存、复制、录音、接入和同步的状态讲清楚，最后用短动效连接状态。首页所有模块应保留；这份报告不提出删减首页内容或恢复此前被否决的整体改版。

现有优点应保留：各页固定窗口尺寸；中英文切换保留用户原文；共享删除确认显示内容和数量；密钥默认掩码；笔记编辑已有保存状态；录音未配置转写时仍可保存音频；天气支持海外城市及当地时间；减少动态效果会停止已测天气粒子；AI 接入会先展示配置变更确认；NAS 恢复预览说明覆盖影响。

标记含义：**已复现**表示本轮实际操作和截图/状态共同支持；**体验判断**表示可见界面带来的理解或发现成本，不等于程序错误；**建议**需要后续样机或用户验证。P1 优先处理核心操作受阻，P2 处理易误解及高频摩擦，P3 为可选完善。本报告中的时长均是建议初值，不是通用标准。

## 中国大陆与海外用户视角

地区、语言、时区和服务账号应分别考虑。中国大陆用户也可能使用英文界面；海外用户可能阅读中文。以下不是审美刻板分类，也没有用本机联网结果推断全球服务可用性。

| 维度 | 大陆用户需要确认 | 海外用户需要确认 | 当前证据与建议 |

## 动效：保留什么、增加什么、减少什么

页面切换、按钮按压、图标、卡片重排、天气和删除确认已经存在动效。当前问题不是“完全缺动画”。这次采样中，切页首张仍是旧页，随后进入新页；未据此认定存在可见空白闪烁，也不把截图采样耗时当作真实帧率或输入延迟。

| 操作 | 当前观察 | 调整建议 | 建议初始时长 |
| --- | --- | --- | --- |
| 展开 / 收起 | 已有从停靠边展开的方向关系 | 保留，优先确保首个输入可操作；不加新的整窗系统动画 | 在现有范围内调优，真机测 60/120 Hz |
| 切换页面 | 已有选中态与内容过渡，键盘左右切页有效 | 先保持当前即时切换。若后续调整，使用轻淡入或极小位移，避免整页横向飞入、等待动画结束才可操作 | 100–160ms，可取消 |
| 首页重排 / 调尺寸 | 71（本地截图：`71-layout-in-progress-zh.png`） 中间卡片跨过邻卡；测到位置动画 780ms | 优先减少：缩短位移，限制瞬时裁切/重叠。拖动中跟手，松手再短暂落位，不让内容重排后长距离漂移 | 约 220–360ms，再与当前实机对比 |
| 新增待办 / 笔记 / 链接 / 指令 | 新条目出现，但用户未必立即确认它的位置 | 增加局部行展开+一次柔和底色，保留输入焦点；不要让整个列表重新播放入场 | 140–200ms |
| 完成待办 | 已有勾选和删除线 | 保留，若发生排序移动，先让用户看清完成反馈再平滑让位；取消完成可逆 | 100–180ms |
| 删除内容 | 确认弹窗清楚，取消默认安全 | 保留确认；真正成功后条目收拢、相邻项补位。失败保留原项和可重试提示，不先假装删除成功 | 140–200ms |
| 复制 / 收藏 | 图标已有 hover 和按压，但复制结果主要在远处文字 | 当前条目/按钮短暂变勾选、收藏星星一次轻变化，避免全文位移 | 100–160ms，反馈保留约 0.8–1.2 秒 |
| 笔记保存 | 已有 Saved/更新时间 | 保留文本状态，保存中→已保存小幅交替；不要打字一次闪一下，不新增长成功弹窗 | 80–120ms |
| 录音 | 红点与计时已有，暂停/无转写文案需先修正 | 红点仅录音时低频呼吸，暂停变稳定；结束显示保存中→已保存，重复点按受控。减少动态时保留文字/计时 | 状态变化 120–180ms；不持续跳动整卡 |
| 搜索 | 笔记无结果状态清楚 | 保持输入即时，不让每键都触发列表长淡入；补全请求期间可用轻量加载提示 | 80–120ms 或无动画 |
| AI 额度 / 同步 | 已有大量状态，真实联网速度不在本轮证据内 | 旧数据先显示；新结果变化才做局部过渡，失败保留旧值并说明时间。后台刷新别每次让所有数字从零重跑 | 小面积 150–250ms；现有额度过渡再单独比较 |
| 弹窗 / 气泡 | 多套浮层视觉与关闭规则不完全一致；待处理窗背景过透 | 统一底色、遮罩和退出层级，轻淡入即可，不加弹簧放大 | 进入 120–160ms、退出 80–120ms |
| 风 / 雨 / 雪 / 雷 | 本轮风夹具正常运行，系统减少动态时计数降为 0 | 风保持目前薄、轻、渐散的方向，不重新加强成云烟；正文区域不叠加强运动。用户主动控制天气动效 | 持续环境效果降频/停止，而非统一加速 |
| 全局动态图标 | 当前大量按钮在 hover/点击会动 | 减少无语义的统一描边/旋转；刷新才旋转、播放才变暂停、复制才变勾选。普通导航更克制 | 单次 100–160ms |

可增加一个跟随系统的“界面动态效果”偏好，默认跟随系统；它应控制位移与持续装饰，不能取消必要的状态文字、焦点和错误提示。天气已有单独开关，可继续保留。不要用动画替代长操作的进度、取消和失败恢复。

## 证据限制与下一轮验收

这是一轮覆盖桌面各模块的体验审查，不是“每个账号、每个平台、每种外部环境均通过”的全量认证。没有连接或修改真实 NAS，没有调用用户真实剪贴板、摄像头、麦克风或工具配置。媒体使用 Chromium 虚拟设备，录音编码、保存和回放走当前应用路径；密钥、主审查窗口列表、AI 历史和部分服务状态使用夹具；补充 AI 接入回归中可能显示本机窗口的图标及短名称，不把它们当成跨平台窗口能力验证。后段为稳定连续截图抑制了隔离窗口失焦自动收起，未将这部分执行声称为真实失焦行为验收。

本轮运行 `tests/nas-settings-card.electron.js`、`tests/ai-sources.electron.js` 均通过。日志中的无效 JSON / 保存失败为故障夹具产生，不能当成真实用户事件。没有运行全量 `npm test`，没有打包、安装或发布。

仍需单列：真实 Windows 原生能力、macOS 多屏四边拖动/睡眠唤醒/系统权限拒绝、真实音乐播放、真实 AI 账户与授权回流、北京/新加坡转写账户与网络、真实 NAS 配对及双机同步/冲突/媒体恢复、fnOS 伴侣网页和安装向导、官网多语言与下载完整路径。大陆与海外真实网络可用性需要分别在相应网络和账号环境下验证，不能用这一台 Mac 的结果替代。

建议执行顺序：先 F01/F02/F03/F05/F06 及窄屏可达性 → 修正误导状态和配置解释 → 解决指令新增与备份发现问题 → 小范围动效原型对照 → 大陆/海外各做新手与熟练用户任务测试。每批改完用相同资料、尺寸、语言和路径复拍；不同时颠覆布局、颜色和动效，以便确认改善来自哪里。
