# 风片减淡与去除烟状轮廓

2026-10-26，macOS Electron，隔离用户目录与固定天气响应。截图中的日期与天气为测试数据。

根据用户对上一轮“太明显，像云、像烟”的反馈，取消纹理的明亮中脊与分叉，改为低对比度扁平薄片。普通风基础透明度为 0.030–0.050，大风为 0.045–0.065；纹理、进出场与局部消散继续相乘降低透明度。降低纵向起伏、局部弯折和扩散幅度，保留横向剪切、局部拉薄与消散。

- `wind.gif`、`wind-strong.gif`：普通风与大风，中卡片连续 48 帧。
- `wind-large.gif`：大卡片连续 48 帧。
- `rain-wind.gif`：倾斜雨线与淡风片叠加，连续 48 帧。
- 动图缩至逻辑像素尺寸，未经对比度或亮度增强。对应 `*-frame.png` 为第 21 帧原始截图。

验证：

- `node --test tests/sun-weather.test.js tests/sun.test.js`：28 项通过，包含降低后的透明度限制、轻微局部形变、独立消散、片段连续衔接、缓存与不同帧率的轨迹一致性。
- `tests/sun-weather.electron.js`：四尺寸、十语言、全部天气族、设置开关、reduced motion、切页、收起与窗口隐藏回归通过。
- 连续原始截图中，普通风最大 RGB 通道变化为 4/255，大风为 6/255，确认效果很淡且仍有像素变化；数值只描述本次固定画面，不能替代主观观感验收。
