# 待办提醒可靠性与摘要验收 · 2026-10-28

本轮保留 Cursor 已有修复，并补齐提醒消费、持久化、同步、截止时间去重、积压展示和错误恢复。测试均使用临时工作区、隔离 AI 凭据和模拟故障。

## 最终行为

- 截止前一小时提醒；错过窗口且未展示过的任务会补提醒。未展示的排队项不写 `remindedAt`，关闭再开启、正常退出或进程重启后仍能恢复。
- 由真实气泡完成入场的受信 IPC 确认展示；工作区 `todo-reminders.json` 原子保存回执，再回写界面与 SQLite 同步队列。窗口故障恢复沿用同一条提醒，不再次写入消费记录。
- 去重身份为任务 ID 与解析后的截止时刻，兼容等价时区格式；修改截止时间会清除对应旧回执，旧截止提醒不会吞掉新提醒。
- 桌面 SQLite 的本地写入/拉取及 NAS 伴侣写入共用相同截止时间的单调合并规则，保留较新的提醒时间和其他字段的新值。截止变化不继承旧标记。
- 批量回执一次原子写盘、一次界面事件和一个 SQLite 事务，避免逐条保存造成重复扫描与同步；无新标记不触发网络同步。遵守迁移只读、恢复暂停及工作区切换保护。
- 同时至少三条过期任务合并为一条摘要，其余待办独立排队，不被 AI 新事件丢弃；点击摘要展开待办并高亮对应条目。标题、说明支持十语言及气泡显示期间切换语言，事件身份不变。Windows 原生能力关闭时仍只关闭气泡，可从待办页查看。
- 排队后删除的任务不再展示；旧工作区发出的迟到调度不进入新工作区。
- 保存失败保留原文件与未保存状态，通过持久错误栏显示原因及修复提示。错误仍存在时重试返回失败；点击真正的修复按钮成功后清除该作用域错误。损坏文件不静默重建，需恢复备份后重试。
- AI 待处理故障测试明确捕获并断言注入的 ENOSPC 告警，输出预期夹具标识；生产告警保持不变。
