# 工作台深度检查与修复 · 2026-10-28

本次检查聚焦改版相关的异步保存、删除、状态刷新、媒体生命周期、笔记预览和交互边界。所有复现使用隔离工作区、静音WAV及内存密钥IPC，不读取真实密钥、不操作生产NAS。

## 已确认并修复

1. 密钥新增成功后的列表读取期间，用户输入的新草稿可能被旧保存流程关闭。现在列表刷新完成后再次检查会话和草稿；新输入保留，提示明确为待保存。
2. 旧保存失败可能修改重新打开的表单反馈。现在按创建会话隔离，旧错误仅通过独立错误栏报告；当前保存失败也进入统一持久错误路径，必填校验仍留在表单内。
3. 单条及批量录音删除忽略文件删除结果，可能移除仍未删除的音频对应条目和转写。现在单条失败不移除，批量仅移除成功项并保留失败选择；IPC等待期间路径改变的新版本不移除。修复按钮重新走确认，不绕过删除确认。
4. 删除范围内的音频文件已缺失时，允许清理其条目；保留目录、名称和符号链接检查，读取与定位仍不允许缺失文件。
5. 删除错误提示改为检查占用与文件夹权限，覆盖十语言，避免把本地文件失败引向网络/登录检查。
