## 本次修复

1. **原生隐藏与网页可见状态不一致**：实测 `BrowserWindow.isVisible()` 已为 false，Chromium 仍可能保持 visible，且部分原生 show/hide 事件未发出。增加独立的原生可见状态通知，以 200ms 检查兜底、按变化去重；窗口销毁时清理。隐藏时停止天气/背景动效、镜子摄像头与笔记收纳动画，暂停回放、遮蔽密钥、关闭待处理浮层；重新显示不自动打开摄像头。主动开始的录音继续进行。
2. **窗口可能无法显示**：构造窗口时已指定 `hiddenInMissionControl: true`，之后再次调用同名 setter。当前运行环境中重复调用使原生可见状态异常；移除重复调用，保留构造配置及既有层级。
3. **快捷键录制 Esc 竞态**：同一按键经 DOM 与主进程 IPC 两路到达，后到的一路可能收起面板。加入相同按键的短时间去重；回归两种到达顺序及下一次正常 Esc。
4. **官网下载弹窗误关闭**：原生 dialog 的内边距和遮罩都以 dialog 为事件目标。改为按坐标判断真正遮罩，且按下、点击均在遮罩才关闭；弹窗内留白保持打开，Esc 和焦点恢复正常。未改视觉样式。
