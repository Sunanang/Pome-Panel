# 笔记交互与单角收纳动画验收

日期：2026-10-29，分支 `dev`。使用真实 Electron 主进程和渲染层、独立临时用户目录及样本笔记；未改动真实用户笔记、密钥与 AI 配置。保留本轮之前的工作区改动。

## 完成的行为

- 首页去掉预览/编辑切换，始终显示可恢复草稿；输入、失焦和退出时保存草稿。点击保存收进独立笔记库，不自动切页。
- 本地入库成功后才开始抽离：原文立即清空，最近的一角先飞向顶栏笔记，其余网格按距离延迟，弯曲跟随，最终缩小消散。正式时长 620ms。动画期间可继续输入下一条，完成回调不修改输入内容。
- 笔记页普通点击正文进入编辑；保存或 Ctrl/Cmd+S 成功后切回预览。自动保存保留编辑态。链接、键盘 Enter、鼠标拖选可正常使用。
- 使用 Markdown 原文偏移和实际字体测量对应可见字形。标题、正文、列表与代码块的预览→编辑→预览误差均小于 2 个 CSS 像素；不是直接复制两个不同布局的 scrollTop。保留单篇笔记的会话内位置。
- 保存失败保留内容与编辑态，走持久错误栏重试；首页多键写入部分失败时回滚原存档。连续收纳、下一条草稿、旧同步投影及重载都有保护。
- 跟随系统或本机「减少动态效果」时改为轻量接收反馈；切页、收起、隐藏和窗口大小变化会清理飞行覆盖层。
- 新增提示进入十种语言资源，更新中英文 README、用户指南和未发布日志。
