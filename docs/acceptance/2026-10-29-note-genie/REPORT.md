# 整模块神奇收纳与无边框编辑

日期：2026-10-29，分支 `dev`。取代上一版单角牵引效果，保留已经实现的草稿、收纳、编辑与阅读位置规则。

## 实现

- 整个首页随笔记组件参与动画，包含原背景纹理、玻璃外观、圆角、标题、保存按钮与正文。
- 动画参考 macOS 神奇效果：靠近笔记 tab 的整条边先拉窄，形成弯曲漏斗；后缘再加速吸入笔记 tab。水平切片保持连续，不再单角拉扯或旋转。
- 正式时长 720ms；初始阶段恢复一个空白随笔记组件，支持动画期间输入下一条，完成回调不会改动新草稿。
- 使用 Electron 工作区自身的原生渲染快照，不使用纯色底图或重新绘制正文。等待已绘制帧，避免截图拿到旧的空白输入；快照期间排除模块外的保存浮层。截图不写磁盘、不发送到外部，也不捕获桌面。
- 快照前短暂保护输入，最长等候 250ms；快照失败、超时、切页或收起时跳过装饰动画，正常保存并恢复输入。存储失败保留原草稿，继续使用原有错误栏重试。
- 笔记正文、首页输入区与标题编辑取消蓝色边框；按钮的键盘焦点提示保留。标题编辑用轻微底线表示焦点。
