# 内容删除确认与剪贴板按钮验收

2026-10-26，macOS Electron。使用隔离用户目录、测试剪贴板和密钥列表；录音删除与密钥删除由测试 IPC 记录调用，不读取真实密钥，不删除用户文件。

## 实现

- 常用指令、待办、笔记、链接、录制、密钥共用深色圆角确认弹窗，展示名称和数量；预览最多三项，超过时显示剩余数量。预览使用纯文本，不渲染内容中的 HTML。
- 覆盖各页面已有的单条、批量删除，录音列表和详情两个入口，以及链接分组和待办分类（含空分类）。录音、分组和分类说明连带删除范围。
- 默认焦点为取消。取消、Esc、点击遮罩、切换页面或收起面板均取消本次删除；Esc 不连带收起面板，Space 不触发面板切换。
- 批量删除绑定弹窗打开时的目标 ID；分类/分组在确认期间新增内容时停止该次删除，避免扩大删除范围；笔记确认后基于最新列表删除目标，保留期间收到的其他笔记。
- 剪贴板文字、网址、图片卡片的收藏和删除按钮共用尺寸与间距变量，按钮间隔为 6 逻辑像素。

## 验证结果

- 全部 Node 测试：980 项，979 通过、1 项跳过、0 失败。第一次沙箱运行中的本地监听被 `listen EPERM` 阻挡；在允许本地监听的环境重跑通过。密钥竞态测试已适配确认弹窗，并补验取消时保留待处理的编辑读取。
- Electron：`content-delete`、`todo-board-fixes`、`notch-focus`、`retained-workspace`、`clipboard-generation` 五组通过。
- 新确认验收覆盖单条/批量的打开、取消、确认，取消时不触发删除 IPC，默认焦点与恢复焦点、Esc、Space、遮罩、收起与切页取消、并发弹窗拒绝、纯文本预览、十语言边界，以及确认期间新增分类内容的保护。
- 文字、网址、图片三类卡片修复前重叠约 4px，修复后测得最小间距 5.97px（动画期间取样）；修复后的收藏与删除分别可用。删除 IPC 计数见 `result.json`。
- 本地化生成资源、语法和 `git diff --check` 通过；新验收已加入 `npm test`。
