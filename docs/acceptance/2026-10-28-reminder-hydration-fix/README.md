# 待办提醒：导入与工作区切换保护

2026-10-28。修复此前 Cursor 改动审查中已复现的回归；保留 Cursor 对无效时间的防御、回执清理和写盘失败时接收最新删除/编辑的改动。

## 修复

- 渲染层在异步工作区导入和启动时 SQLite 投影应用完成前，不发送待办提醒调度；旧页面准备重载、工作区切换时同样停止发送。初始化完成后统一重建调度。没有持久化工作区 API 的轻量测试桥接保持原行为。
- 主进程在绑定/重建提醒状态前，拒绝没有绝对工作区路径的请求，返回 `workspace_not_ready`；路径与当前工作区不一致则返回 `stale_workspace`。因此启动临时空投影和迟到的旧工作区请求不会清空当前回执。
- 有效工作区真正删除任务后，Cursor 的孤立回执清理仍然执行。仅清理孤立回执的写盘失败不阻断调度；真正回执写入失败的错误仍可见。
