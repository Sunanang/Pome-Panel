## 已修复

1. 录音启动异常和缺失媒体 API 时，内部刷新仍处于 pending，会把刚显示的失败原因覆盖为等待授权。改由独占任务退出 pending 后统一刷新。
2. 录音保存 toast 的查看动作只切页，用户另选录音后会打开错误条目。动作现在定位该 toast 对应的录音，已删除条目不会被恢复。
3. 启动后的延迟恢复和权限检查结束会主动抢焦点，并可能重开用户刚隐藏的面板。恢复改为非激活显示，尊重显式隐藏、系统授权、测试资料与退出状态。
4. 主面板在 macOS 使用 status 层级后，通知仍在 floating 层级。通知现在跟随主面板基准层级并保持 relativeLevel=1。
5. 打包版忽略显式测试资料标记，可能启动真实权限检查、托盘和服务，而建窗及激活仍按测试模式处理。所有构建统一保留显式测试隔离。
6. 启动权限自检的 Promise 失败缺少捕获。现在处理失败并继续安全的可见性恢复。
7. 引导页较早的设置读取可能覆盖新广播的快捷键和完成状态。加入读取版本保护。
8. 密钥表单显示明文时，同一物理 Esc 经两个通道送达，第二次可能误收起面板。恢复重复事件保护。
