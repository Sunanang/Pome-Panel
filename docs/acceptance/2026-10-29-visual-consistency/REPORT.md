# 工作台样式与操作修复

日期：2026-10-29；开发分支：`dev`；版本：`0.11.0`，改动记入未发布日志。

## 改动

- 全局滚动条统一为 4px 细轨，横向与纵向共用普通、悬停、按下颜色；移除系统粗条和箭头。
- 链接行取消横向位移，限制最小宽度并预留滚动空间；长标题、分组选择和三个操作按钮保持在完整背景内。1240px 与 740px 均无横向溢出。
- 链接、录制、密钥使用与笔记相同的实色阅读底面；设置恢复独立实色卡片。
- 待办分类和任务恢复分块；移除重复的页标题，统计、说明和添加分类保持单行，长说明支持悬停查看全文。
- 剪贴板分类使用 200ms 滑动选中背景和 160ms 内容过渡，重复点击当前分类不重播；快速切换、离页、收起和减少动态效果均清理动画，过滤不修改内容。
- 首页移除常驻布局编辑按钮与提示行，保留右键菜单入口。
- 首页及笔记库移除预览/编辑切换按钮；保存和阅读位置规则沿用笔记工作流。笔记标题直接编辑，移除独立「修改名称」按钮；编辑框没有蓝色边框。
