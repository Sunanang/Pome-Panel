| 严重度 | 触发与原问题 | 修复与回归 |

| P1 | 密钥库 JSON 损坏、解密失败或包含异常行时返回空数组；随后保存、删除或同步可能覆盖旧文件 | 严格区分不存在与无法读取；异常时阻断写入/同步，保留原字节、草稿与错误恢复入口。目录刷盘在 rename 后失败时按精确字节确认本次是否已保存，避免重试生成重复密钥 |

| P2 | 收件箱 rename 已成功但目录 fsync 报错，内存仍旧，之后一直误报外部修改 | 只在磁盘字节精确等于本次写入时协调内存状态；仍向调用方报告耐久性错误，后续去重、读取与写入可恢复 |
| P2 | 首页长按等待或拖拽过程中按 Esc、取消、切页、失焦或收起后，旧定时器/拖拽状态仍可能交换并保存卡片 | 统一清除待启动和进行中的拖拽、预览及指针捕获；异步回调校验本轮按压身份与当前编辑状态 |
| P2 | 镜子启动→取消→重启，两次权限/采集/播放结果乱序返回，旧流可能接管或泄漏 | 启动请求有代次；旧结果不能接管或清除新状态，过期轨道立即释放。合成轨道回归验证每条只停止一次 |

## 桌面与 NAS 实际界面验收

1. **首页与布局：通过。** 四尺寸互换保留足迹；取消待启动/进行中拖拽，后续移动、松手不改变布局或存储。Dock 离开后不会被旧帧放大。证据：`layout-cancelled.png`，配合 DOM 状态和存储断言。
2. **摄像头、天气与天文：通过受控验收。** 两次镜子请求乱序返回只接纳最新请求，最终两条合成轨道均释放；天气开关、reduced motion、切页/收起/隐藏仍暂停。DST 前后对照中太阳点重新落在曲线上；失效时区恢复后仍可选择城市。证据：`mirror-cancelled.png`、`sun-dst-before.png`、`sun-dst-after.png`。
3. **待办、笔记、链接、录制：既有回归通过。** 覆盖分类、截止时间预览不提交、同步草稿/焦点、Markdown、公开链接、录音入口与持久化；未新增改变这些正常流程的产品逻辑。证据：本轮 `todo-deadline.png`。
4. **密钥、设置、通知与 AI：通过。** 密钥损坏时禁用写入并保留草稿，修复后重新读回原记录；快捷键冲突/写盘失败保留旧绑定；额度与通知既有回归通过。证据：`credentials-unreadable.png`、`credentials-recovered.png`。通知测试另修正一处立即读取异步 IPC 结果的竞态，等待实际错误态后断言。
5. **NAS 网页：通过隔离服务验收。** 真实页面与 API 加载测试 WAV、坏录音只保留转写；媒体替换/迟到请求/离开恢复有回归断言。390px 导航、语言及登录状态均在视口内。证据：`nas-recording-valid.jpg`、`nas-recording-corrupt.jpg`、`nas-recording-mobile-before.jpg`、`nas-recording-mobile.jpg`。

所有证据位于 [截图目录](screenshots/project-audit-2026-10-25/)。截图是本轮真实 Electron 或 IAB 捕获。天气、日期、账户与资料均为测试夹具。
