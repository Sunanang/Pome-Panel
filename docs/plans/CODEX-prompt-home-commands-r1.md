# Codex 实现提示词 · 首页「常用指令」备注胶囊 + 悬停浮层（dev）

**分支：只在 `dev` 开发提交，禁止动 `main`。**

## 设计参考
[home-commands-r1](https://drive.google.com/drive/folders/1j9floC6_oCcLt9mTxVD58r5Z1itSP3ig)：compare / mini / small / medium / large / tip-note / tip-none / tip-long / edit / spec。
设计图卡片尺寸是估算重建的，**实际尺寸以现网为准**；只改列表行与悬停浮层，模块外壳（标题、清空按钮、输入框、背景图、液玻、编辑模式）保持现网不变。

## 现状
首页常用指令模块（data-home-module="commands"）每条两行：第一行指令（截断）+ 复制/删除，第二行单独显示备注或「添加备注…」。已有悬停 tooltip，但只显示完整指令。先在代码里找到这一行的渲染、备注编辑和现有 tooltip 实现，在其基础上改，不要另起一套数据结构。

## 要改
### 1. 单行布局
- 每条一行：`指令（flex:1，单行省略号，等宽字体保持现网）` → `备注胶囊` → `复制` → `删除`。
- 行高约 30px（原约 37px），padding 3/4/3/9，gap 6；其余颜色、圆角、按钮样式沿用现网。
- 删除原来的第二行（备注 /「添加备注…」）。

### 2. 备注胶囊
- 高 18，圆角 999，字号 10px，`max-width:56px`（≈4 个汉字），单行省略号。
- 背景 `rgba(255,255,255,.06)`，边框 `rgba(255,255,255,.09)`，文字 `#8A8A8A`（以 spec.png 为准，可微调到与现网 token 一致）。
- 没有备注：不占位。

### 3. 添加 / 编辑备注入口（点胶囊位置）
- 有备注：点胶囊进入编辑。
- 无备注：鼠标悬停该行时，在胶囊位置出现虚线 18×18 的「＋」，点它进入编辑；不悬停时零占位。
- 编辑框约 76×20，原位替换胶囊；placeholder「备注 ≤6字」，右侧显示 `n/6` 计数（超过 6 字计数变警示色；是否硬限制按下条）。
- Enter 或失焦保存，Esc 取消，清空后保存即删除备注。
- 数据兼容：旧数据里的长备注照常保存与显示（胶囊截断、浮层看全文）；新输入建议 ≤6 字，**不要截断或改写已有数据**。新输入是否硬限制 6 字：只做提示与计数，不硬拦（与旧数据兼容一致）。
- 不加新的按钮，不加右键菜单入口。

### 4. 悬停浮层（改造现有 tooltip）
- 自绘浮层，不用系统 `title`；悬停约 450ms 后出现，140ms 淡入。
- 位置：行下方 6px（空间不够时翻到上方，并限制在面板可视区内）。
- `max-width:260px`，padding 8/10，圆角 12，`backdrop-filter: blur(20px)`，阴影 `0 12px 32px rgba(0,0,0,.45)`，深色液玻，与面板风格一致。
- 第一行：完整指令，11.5px 等宽，可换行。
- 第二行：完整备注，10.5px，约 46% 白，可换行；无备注则只有第一行。
- 出现条件：指令文本或备注胶囊**被截断**时才出现（用 scrollWidth > clientWidth 判断）；mini 尺寸只要有备注就出现（mini 没有胶囊）。
- 编辑备注中、拖拽/编辑模式中不出现；鼠标移开立即消失。

### 5. 尺寸
- mini：只显示指令，无胶囊、无复制/删除（与 mini.png 一致；若现网 mini 有按钮，以设计图为准去掉）。
- small / medium / large：指令 + 胶囊 + 复制 + 删除。small 下指令可见宽度较窄属预期，靠浮层看全。

## 不要做
- 不改模块外壳、背景图、输入框、编辑模式拖拽和尺寸规则。
- 不改指令/备注的存储格式（字段名沿用现有）。
- 不加首次引导、右键菜单。

## 验收
1. 每条只占一行，行高明显降低；无备注不留空位。
2. 悬停无备注行出现虚线「＋」，点后可输入备注，Enter/失焦保存、Esc 取消、清空删除。
3. 点已有胶囊可编辑；长备注胶囊截断，悬停浮层显示完整指令 + 完整备注。
4. 未截断时不弹浮层；mini 有备注时弹浮层。
5. 复制、删除、输入新指令、清空、编辑模式、四档尺寸均无回归；现有测试通过。
6. 仅 dev 提交，说明本地验证步骤。
