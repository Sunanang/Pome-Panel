把设置页从现网「顶部子导航 + 主栏/侧栏双列堆叠」改成 **左侧分组导航 + 右侧当前组内容**（方案 A）。**只改信息架构与布局壳**；右侧每个控件、状态、文案、弹窗逻辑必须以现网为准，禁止摘要简化、禁止发明字段。

## 硬约束
1. **UI 与现网统一**：复用现有 `settings-card`、`settings-device-row`、`workspace-button`、液玻/磨砂、状态 pill、输入框深色样式；不要换视觉语言，不要金色/emoji，不要设置内搜索。
2. **右侧卡片同宽**：同一组内各模块卡片宽度一致。
3. **禁止发明字段**：现网没有的控件/状态/弹窗不要加；现网有的不要删（可搬家到新分组）。
4. **文案用线上渲染文案**，不要抄 HTML 写死备用字。已知纠偏：
   - AI 卡标题是「AI」，不是「AI 配置」；副标题「AI 干完活提醒你，顺便看看额度。」
   - 录音卡/弹窗标题「录音转写与命名」
   - 显示·待办副标「待办分类」；首页开关「AI 完成提醒」
   - Cursor 默认 Token 状态「未保存 Token · 自动尝试本机登录」等以 i18n/运行时为准
5. **NAS 全部展开**：不要「高级/详情」默认折叠；连接设置、同步详情、故障处理内容直接展示（可用分区标题，不要藏进折叠里）。
6. **数据页**：本地目录 + **导出**一块 + **恢复/备份**一块（分开两块，不要并成一个按钮行完事）；NAS 同步仍是侧栏独立项。
7. **录音并入 AI**：录音转写与命名卡放在 AI 组，不再单独顶栏「录音配置」。
8. **平台条件行保留**：自动会议（含状态标签与覆盖说明）、Windows 原生能力等按现条件显示。
9. 改动可回滚；现有测试尽量过；i18n 键按项目惯例补/迁。

## 必须修（Lando 指定，设计图有但实现要修）
### 外观 · 天气动态效果 ↔ Open-Meteo 归属说明之间不要分割线
现网结构（`renderer/index.html`）：
- `.settings-weather-effects-row`（开关行）
- 紧随其后的 `.settings-weather-attribution`（「本应用的天气数据由 Open-Meteo 提供。」）

现网 CSS：天气开关行 `border-bottom: 0`；attribution 是普通说明段落（`padding:2px 0 12px`），**中间没有一条独立分割线把两者拆开**。

实现时：
- 不要把 Open-Meteo 说明做成带 `border-top` / `border-bottom` 的独立 `settings-device-row` / `sl-device-row`。
- 开关行与 attribution 之间禁止再出现 hairline；attribution 紧贴开关行下方，作为该设置的附属说明。
- 下一行（温度单位）与天气块之间才可以有正常的行分割。

（设计稿 A-r3.3 外观页曾在开关与 Open-Meteo 条之间多出一条分割线——**产品实现不要照搬这条线**。）

## 侧栏六项（固定顺序）
| 侧栏 | 收入现网内容（搬家，不丢） |
|------|---------------------------|
| **常用** | 语言、唤出快捷键、面板位置、默认展开页、开机自启、手动/自动会议（含信号标签与覆盖说明）、顶部气泡、Windows 原生能力（仅 Windows） |
| **外观** | 面板尺寸三档、天气动态效果 + Open-Meteo 说明（无中间分割线）、温度单位、界面动态效果、首页镜子配图 |
| **显示** | 工作区 6 开关 + 首页 11 开关（现网 2 列网格样式对齐）；容量不足等提示逻辑保留 |
| **AI** | AI 卡（8 家 + 计数 + 能力说明 + 接入/修复/断开）→ 6 家 Token 区块 → 录音转写与命名卡；全部相关确认弹窗/录音弹窗 |
| **数据** | 数据文件夹；导出资料备份；恢复资料备份（分块）；恢复对比确认 |
| **NAS** | 摘要五态 + 复制诊断；连接设置（地址/配对码/步骤/吊销/备用地址/每 endpoint HTTP 开关/警告）；同步状态与迁移/恢复；10 条内容同步行；故障处理全文展开；全部现网弹窗 |

去掉现网设置顶栏子导航（AI 工具 / 本机设置 / 录音配置 / 显示功能 / 资料与备份 / NAS 同步）的「主入口」角色；改为左侧六项。若 `experience.js` / tray / 深链仍滚动到旧锚点，映射到新侧栏项。

## AI 组实现要点
- 8 家固定顺序：Cursor → Codex → Grok Bot → Claude Code → Grok → Copilot → Antigravity → Manus。
- 行布局对齐现网：`.ai-source-main` 横排（图标 | 文案 | 操作）；`#tab-settings .ai-source-row` 约 `padding: 13px 0`；行间 `border-top` hairline。**禁止**把图标/文案/按钮竖着叠成一团。
- Token：Cursor/Codex「获取并保存」+ 手动填写；Grok 含 xAI 团队 ID；Manus 含接收完成提醒与检查/测试。
- 录音弹窗：复用现网 `#transcription-settings-backdrop` / `.transcription-settings-card` 结构与深色输入，不要白底输入框。

## NAS 组实现要点
- 摘要行五态文案与主按钮按现网 `ui-simplify`（未配对/已同步/离线/需处理/已暂停）+「复制诊断信息」。
- 按钮组间距对齐 `.settings-nas-sync-actions`（约 8px gap），不要粘连。
- 迁移/恢复等按钮按**状态显隐**，不要把互斥按钮同时常驻铺开（设计全量图只是清单，不是某一瞬间的 DOM）。
- 12 个现网弹窗都要还能打开，逻辑不砍。

## 交互
- 点左侧一项：右侧只渲染该组；高亮当前项。
- 默认进入项：建议「常用」（或保留上次选择，二选一写进实现并注释）。
- 无设置内搜索。
- 窄高窗口：右侧内容区内滚；侧栏保持可见（可参考设计图）。

## 验收
1. 六项侧栏可切换；无搜索；卡片同宽。
2. AI 页一眼能看到 8 家横排列表 + Token + 录音卡；行距/分隔线正常；接入/断开/修复弹窗可用。
3. NAS 页展开完整；五态摘要按钮有间距；配对/同步/迁移/恢复主路径仍可用。
4. 数据页导出与恢复分块；恢复对比仍在。
5. **外观：天气动态效果开关与 Open-Meteo 说明之间没有分割线。**
6. 显示开关、面板尺寸、镜子、会议模式等原逻辑不回归。
7. 仅 `dev` 提交；说明如何本地打开设置逐项点验。
