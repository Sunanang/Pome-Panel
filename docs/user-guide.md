## 界面与识别语言

桌面和 NAS 网页支持 English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Русский 和 Português (Brasil)。桌面首次启动按系统语言选择，未支持的语言回退英文。「设置 → 本机与唤出 → 语言」可选择跟随系统或上述十种语言；偏好只保存在本机，不参与 NAS 同步，切换保留当前输入与用户原文。日期数字使用界面语言和系统地区格式。

新增语言翻译为初稿，尚未经母语人工校对。黄历传统历法内容保留中文。

「录音转写与命名」中的录音识别语言独立选择中文或英文，不随界面切换改变，录音中的重连也保持开始时的识别语言。智能命名按内容语言生成，历史标题、笔记、项目名、AI 摘要和自定义地名不自动翻译。

NAS 网页通过官方 SDK 读取当前宿主用户语言，兼容环境回退浏览器；可手动切换并在此浏览器保存偏好。NAS 安装、配置、升级、卸载向导及 Windows 安装/卸载仅提供中英，随系统语言；应用内手动选择不改变安装器语言。macOS 使用 DMG 与 Finder，系统权限用途说明提供上述十种语言，不另建卸载向导。

[英文指南](../README.en.md)与[英文更新日志](../CHANGELOG.en.md)覆盖面向用户的使用和历史发布说明，内部研发文档保留原文。

## 面板怎么摆

折叠态是一颗短胶囊：贴在上下边时大约 85×9，贴在左右边时竖过来。点一下展开；按住拖动则搬家。松手时按指针离四边的远近吸附，坐标写进本机设置。沿这条边，离屏幕一端大约 120 逻辑像素以内时，展开面板会靠向那个角。没有自定义位置时，胶囊在顶部居中：macOS 上是菜单栏正下方，Windows 上是工作区顶部，都不会压住任务栏或菜单栏。

展开后各页内容区都是 `1240 × 540`。切换页面只换内容，不改窗口大小。窄屏和矮屏会留出边距。

菜单栏托盘可以重新显示面板、设置唤出快捷键、开机启动。默认唤出是悬停后按空格，也可以改成别的组合键。

## 里面有什么

| 页面 | 做什么 |
| --- | --- |
| **首页** | 上面的 Bento。至少保留一个组件；隐藏后其余格子重新铺满 |
| **待办** | 默认四个可改名的分类（「课程 / 自媒体&写作 / Vibe coding / 日常」），可增删至 1–8 类，内部键为 P0–P7，可见顺序仅保存在本机。新建默认当天 23:30，按截止时间排序。顶部气泡在到期前一小时提醒一次；若错过提醒窗口且仍未展示过，重新开启或启动后补提醒；同时至少三条过期任务合并为一条摘要。按实际展示记录同一任务与截止时间的状态，排队和关闭提醒不消耗未展示项；已收到到期前提醒时不再补弹过期提醒；改截止时间后重新计算。点击气泡展开并打开待办，尽量滚到并高亮对应条目。已有条目打开日期编辑器不写入；未设置截止时间时显示待选择提示，主动选择有效时间后才保存。同步更新保留未提交草稿和手选日期；离开待办或收起面板会关闭日期弹窗。备份、恢复及 NAS 覆盖包含全部八类待办与分类名 |
| **笔记** | 首页速记保存后进入笔记库，可搜索、重命名、编辑和删除 |
| **链接** | 只保存公开的 http/https。抓取标题时拒绝本机、内网和不安全重定向 |
| **录制** | 音频写在本机 `recordings/`。可选百炼 Qwen3-ASR 实时转写，API Key 经系统安全存储或环境变量读取 |
| **密钥** | 账号、密码和 API Key 使用系统安全存储，页面不能直接读出明文 |
| **设置** | 录音转写与命名、AI（完成接入与额度 Token）、显示（工作区与首页开关）、NAS 同步、镜子封面、默认展开页、唤出快捷键、面板位置、数据目录、开机启动 |

首页 Bento 的「AI 完成」模块可回看 Codex / Claude Code / Cursor 的完成事件及 NAS 同步历史（旧 GPT 历史保留，显示为“其他”）。模块支持四档尺寸：迷你显示未读数与最新来源，小号显示最近 3 条，中号显示最近 5 条，大号显示 10 条及项目摘要。记录按模块尺寸分页（迷你 1、小号 3、中号 5、大号 10 条），不再提供“查看全部”模式。第 1 页只显示“下一页”；后续页显示“上一页”和当前页码，仅在确实有下一页数据时显示“下一页”，总数不超过一页时隐藏分页区；迷你尺寸始终隐藏整个分页区。新完成记录到达时保留当前页，翻页后列表回到顶部，卡片尺寸保持不变；「全部已读」通过逐条保存标记已有记录。首页 tab 未选中时在文字右上方显示未读角标（超过 9 为 9+），损坏时显示 !；选中首页时隐藏。模块关闭时角标显示小点，点击转到首页模块设置；模块开启时点击返回首页并高亮。关闭 AI 完成后在原空位显示淡色“添加模块”入口；再开启会保留其他组件的尺寸和位置，重新开启时优先恢复原位置，空间不足只缩小 AI 完成本身。记录先落盘再提醒，点击记录时标已读；按接收时间保留最新 100 条，超出后自动清理最早记录（含未读），新增、启动载入和读取使用同一规则。去重使用来源的完成事件 ID，或来源、任务与完成时间/回合序号生成的稳定身份，延迟重试和重启重投不会再提醒；同一会话的新回合仍正常接收。去重信息随记录保留，数量淘汰时一起清理；已淘汰事件再次投递不保证去重。缺少明确身份的旧钩子事件仍接收，以补充的完成/接收时间和内容生成身份；没有原始 ID 的旧事件无法保证跨时间重投仍被识别为同一事件。收件箱损坏时显示“备份损坏文件并重建”，确认弹窗展示完整备份路径和可能无法恢复历史的影响；取消继续暂停，确认后先保存并校验原始字节，再原子建立空收件箱。收件箱在本机 userData 落盘，并通过 NAS 同步完成记录及已读状态；不参与普通资料备份。同步按来源与稳定完成身份合并，拉回历史不重弹通知；本机窗口和目录信息不跨设备。新增、载入和跨设备合并统一保留最新 100 条，NAS 同样裁剪并留下删除标记，防止离线旧记录复活。首次配对按已有的本机/NAS 为准流程处理；旧 NAS 伴侣需先升级以支持 AI 完成集合。点击记录直接打开来源软件，不定位聊天或会话：Codex 打开桌面版，Cursor 打开 Cursor，Claude Code 打开终端。macOS 优先复用 cwd 对应的 Terminal 标签页，找不到时新开终端并进入该目录；Windows 优先 Windows Terminal，回退 PowerShell。没有 cwd 时只打开终端；目录须为存在的绝对目录。未安装或打开失败时显示轻提示。

「设置 → NAS 同步」提供 `.pome-backup.zip` 本机资料备份，即使未配对也能导出实际待办、分类、笔记、链接、指令、剪贴板和录音媒体。v1 清单记录应用版本、集合条数及 SHA-256；恢复先校验并保存当前资料快照，替换失败会回滚。密钥、AI Key、配对、同步控制状态、首页布局和系统设置不进入普通备份，恢复保留当前凭据与设置。

已配对设备恢复后暂停同步，重启继续暂停。需要重新预览并确认本机覆盖 NAS 的新增、修改和删除影响；本机或 NAS 变化使预览过期。NAS 必须先保存并读回验证快照，覆盖按服务器版本原子提交，核验成功后恢复同步；不支持快照的旧伴侣禁止覆盖。本轮没有“先拉取再合并”的执行入口。最近覆盖可在 NAS 没有后续变更时回退快照，回退产生新版本并保持同步暂停。

同步结果按内容类型显示，录音元数据与音频分开；超过 6 MiB 或缺失的音频不会显示为已传输。本机备份仍保存完整超限音频；本机音频不完整且 NAS 已有完整音频时禁止破坏性覆盖。笔记冲突以新的笔记 ID 保留版本，按来源及版本去重，标题不会递归生成“副本的副本”；待办维持服务器实际接受的版本顺序，不做字段级自动合并。密钥新增与编辑默认使用密码掩码。

剪贴板历史默认关闭，可从菜单栏或「设置 → 显示 → 工作区」打开。它只在本机轮询，不占用全局快捷键。Windows 上没打开原生能力时，点击条目是复制，再用 Ctrl+V 粘贴。

剪贴板普通历史按复制时间保留最新 100 条，超过后自动清理最早记录；收藏永久保留，不占用这 100 条名额（仍可手动删除或清空）。本地新增、启动载入、资料恢复与 NAS 同步投影使用同一裁剪规则；取消收藏后重新计入普通历史，超限的旧记录立即淘汰。NAS 合并后被淘汰的普通记录会同步删除，避免再次拉回；清理图片时保留仍被收藏或其他记录引用的文件。

Windows 上「汽水音乐」永久隐藏；「当前窗口」与剪贴板自动粘贴需要在「设置 → Windows 原生能力 · 实验功能」里手动打开（见 [Windows 上的几件事](#windows-上的几件事)）。关闭状态下不会改写已经保存的显隐偏好，换回 macOS 时组件还在。

飞牛同步在设置页右侧的「NAS 同步」卡里填写地址和一次性配对码，卡片位于封面图片与本机设置之间。「高级」可配置一个备用外网地址；状态行显示整体同步时间，「详情」逐项显示各类内容的结果和各自同步时间。同步暂停时，恢复预览与快照回退入口直接显示在卡内。设备令牌放在系统安全存储，不写入 LocalStorage。本机工作区仍是数据落点；明文 HTTP 默认关闭，回环地址除外。

飞牛伴侣将同步数据、设备配对、账号同步密钥和请求去重记录保存在数据目录的 `sync-state.bin` 检查点及 `sync-state.bin.transactions/` 增量事务目录，服务重启后继续使用原状态。每次写入只持久化变动，累计 256 个事务再安全合并检查点，旧录音不会随普通修改反复写入；校验、顺序或存储损坏时停止启动并保留原文件。NAS 内部检查点 v3 自动读取并升级旧 v1/v2 数据，旧伴侣不能读取 v3，不可直接降级。备份伴侣数据时必须一并保留检查点、事务目录与 `server-id`；普通桌面 ZIP 备份仍为 v1。清理按原子检查点完成：所有未撤销配对设备已确认的日志前缀可截断；未确认日志默认保留 90 天，超期游标明确要求全量重同步。幂等结果默认保留 90 天，清理后拒绝旧基线请求，客户端拉取并重建待发送请求；远端删除不能被旧队列复活。快照保护最近一次已提交覆盖、30 天回退窗口内的覆盖，以及 24 小时有效期内正在暂存的操作；其他快照默认达到 90 天后清理。准备操作超出 24 小时需要重新预览；回退仍需校验 NAS 没有后续变更。可通过 `FNOS_SYNC_RETENTION_DAYS` 与 `FNOS_ROLLBACK_WINDOW_DAYS` 设置正数天数；处理请求时每小时或累计 256 个事务触发检查。其他实际内容及删除标记不按这些缓存规则清空；剪贴板和AI 完成记录另按各自的数量规则保留。

默认本机数据目录独立使用 `Pome Panel`：macOS 为 `~/Library/Application Support/Pome Panel`，Windows 为 `%APPDATA%\Pome Panel`。首次升级会把旧 `Dynamic Panel` 目录的完整持久化资料复制到新目录，校验复制期间的数据一致性；原目录保留，后续不再共用。新目录已有资料时优先使用新目录，不自动合并旧资料；自定义工作区路径继续使用原设置。复制失败或旧目录在复制期间发生变化时停止启动并提示重试，避免使用不完整资料。

更换本机数据文件夹时，空目录用于迁移当前工作区；已有 `workspace.json` 的目录会提示打开其中的数据，当前工作区先保存到原目录。复制密钥密码时会标记为敏感内容，并从本应用剪贴板历史采集中排除。

Cursor 用量默认自动读取本机 Cursor 登录态。「设置 → AI → Cursor」中的「获取登录」可一键读取并加密保存已登录的本机 Cursor（macOS 与 Windows 均支持）。兼容明文和新版 `cursor-safe-storage:v1:` 加密记录：macOS 只读取系统钥匙串的 `Cursor Safe Storage` 项，Windows 使用当前用户 DPAPI 和 Cursor 自己的 Local State 密钥，不使用 Pome 的密钥解密 Cursor。macOS 可能要求授权钥匙串访问；拒绝后后台不会反复弹窗，可在允许访问后再次点击「获取登录」。读取受限会显示明确提示，不冒充 Token 过期，也不会把密文发送到接口。旧版误保存的 Cursor 设备密文不再作为 Token 使用或同步，自动回退当前本机登录；重新获取登录可替换该旧配置。无需安装 sqlite3 或 Python。保存的有效 Token 优先用于查询用量，本机以系统安全存储加密，并随 NAS 的 AI 配置以加密盒同步到其他已配对设备；失效时回退本机登录态，成功后正常显示额度。点击「清除」会恢复本机登录模式，并同步清除其他设备保存的 Token。未保存的输入不会同步。

首页「AI 额度」只显示已检测到或配置 Token 的来源（catalog：Cursor、Codex、Claude、Grok Bot、Grok、Copilot、Antigravity、Manus）。采用 B 仪表盘马赛克，同屏显示来源，不再切换 Tab。默认展示该 AI 统计周期最短的额度窗口（如 Codex 的 5 小时额度优先于周额度）；周期相同时保留来源顺序，未提供周期时使用来源主统计，主窗口缺失读数时保持未知，悬停或点击展开各窗口细条；余额、积分及无限额度保留原单位，不伪造百分比。迷你最多显示 4 个来源，5 家起显示 3 个来源 +「+N」；小号最多显示最紧急的 4 家，使用等宽 2×2，3 家时空出第 4 格；更多来源在额度顶栏刷新按钮左侧显示灰色「+N」入口。迷你/小号按失效、用完、告急、偏低、过期、正常排序，同级按瓶颈剩余排序；中/大号按设置来源顺序。中/大号 3–4 家同排、5–6 家使用 3×2，超过 6 家时在组件内滚动；不显示接入或摘要占位格。小号和中号只显示非主窗口进度条，单窗口来源不重复画条；大号保留实际窗口条，Grok Bot 的真实周条与同行第一条对齐。所有非迷你格子依次为单行名字与图标、居中环、窗口条及仅含真实时间的底部说明；不显示角标气泡或预留角标行。常规格子的环在名称下方、窗口条上方的剩余空间居中；无条格在名称与底部说明之间居中，无隐藏行占位。中号 3–4 家单排长条格的环位于整格垂直中线，窗口条跟随在圆环下方 10px。同卡环径与格子大小一致：小号 38px，中号 3/4/5–6 家为 72/60/32px，大号为 140/120/80px；实机空间不足时全卡统一缩小。常规布局先给名称、条与脚注留位，再将环在余下区域居中；中号单排长条布局将圆环居中、条随环排布，脚注仍在底部对齐。每家 AI 的窗口条按本家最长标题独立计算标题列，数值列按真实字体下的「100%」宽度固定，数字从列左侧起排；标题/轨道/可见数值间距为 3px/2px；整行按实际可见内容居中，固定数值列中未用到的预留宽度不计入视觉居中，数值位数变化时复用原动画平滑调整整组位置。不同 AI 不强求等长，同一家所有轨道左右对齐，动画中宽度保持不变。窗口详情、数据来源、重置时间与更新时间可通过悬停或点击查看，多窗口超出时在明细内滚动。Grok Bot 是 Cursor Sand 会话池独立卡（使用本机登录或已保存 Cursor Token），与 xAI 的 Grok 分卡展示。都未检测到时显示连接说明与设置入口。首页布局沿用原 `cursor` 模块 ID。额度统一显示「59%」，额度条越满表示剩余越多；剩余 ≤20% 为橙色、≤10% 为红色。缺失数据保持 `--%`；Grok 的预付账本余额直接显示美元，不生成百分比条。Manus 通过官方 v2 接口显示可消费积分余额，不用余额与月度配额推导百分比。

额度窗口名称统一使用「日额度」「周额度」「月额度」「N 小时额度」「N 天额度」；紧凑视图可缩写为日、周、月、5h。Codex 与 Claude 的相同周期采用相同名称，不重复显示「7 天 · 周额度」；Grok Bot 标为周额度；Cursor 标为月额度，并保留 Cursor / Other 分类（非迷你窗口条统一缩写 Cur / Oth；接口字段仍为 auto / other），重置说明不再使用账期或账单措辞。Copilot 按实际池显示高级请求额度、聊天额度、补全额度，Antigravity 保留模型名并在已知时标注周期；Grok 保留已入账预付余额、Manus 保留可用积分，不推测缺失的周期。

Codex 配置手动 access token 后，由主进程向 `https://chatgpt.com/backend-api/wham/usage` 查询实时额度，超时 10 秒；沿用首页的定期刷新与刷新按钮。未配置 Token 或联网失败时，回退读取本机 `$CODEX_HOME/sessions/YYYY/MM/DD/rollout-*.jsonl` 的 `token_count` 记录，按记录时间跨会话选取最新一条，避免旧会话追加普通内容导致额度回跳；默认目录为 `~/.codex`；Windows 还会检查 `%USERPROFILE%\.codex`。两种来源按实际 windowMinutes 展示额度周期、套餐、Credits 与更新时间；仅有周窗口时只显示周额度，额外模型额度按各自名称和周期列出，标签分别为「手动 Token」和「本机 Codex」。重置时间按本地日期显示为「HH:MM 重置」「明天 HH:MM 重置」或「M/D HH:MM 重置」。过期记录的圆环和额度条半透明，并提示「数据过期」；Token 失效显示红色虚线和重新获取提示，网络故障仍保留可用的旧数据。网络故障且没有可用本机记录时保留上次成功的远程数据与原更新时间。各家额度重置时间与 Cursor 的账期结束时间统一按本机时区显示到分钟；一周内用周几+时刻，超过一周（如 Cursor 月额度）直接显示月/日，跨年带年份；Cursor 账期仅有日期时保留日期，缺失时保持未知，底层时间戳保留原精度。Cursor 也保留同一账号的最近成功值并标注刷新失败；退出、切换账号或认证失效时不复用旧账号缓存。可选的 Grok Bot 用量失败不会阻断 Cursor 主额度。刷新按可见性降频，并在已知额度重置后主动更新；展示首页额度面板时先显示缓存并后台查询，30 秒内重复唤出复用缓存，手动刷新仍立即查询。成功变更时环长与数字按 720ms ease-out 同步过渡，窗口细条错开 60ms；中途新结果从当前帧继续，首次从 0 开始，相同值或失败不播放新动画。减少动态效果时直接切换；用完的变灰和划线在过渡结束时切换。

「设置 → AI」按统一列表管理各家完成接入与额度，每个来源的 Token 控件直接放在该行下方。Cursor / Codex 保留获取本机、保存与清除操作；Grok Bot 注明依赖 Cursor 登录；Claude 用量走本机 OAuth；Copilot / Grok / Antigravity / Manus 可配置手动 Token（`safeStorage`），Grok 还需 xAI 团队 ID；只接受 Management API Key，显示以美元计的已入账预付余额，不伪造订阅额度百分比。Manus 使用官方 `https://api.manus.ai/v2/usage.availableCredits` 与 `x-manus-api-key`，只以 `data.total_credits` 作为可消费积分余额。Codex「获取并保存」仅在主动点击时读取本机 `auth.json`，并通过系统安全存储保存；默认收起手动输入框。Token 不写入工作区、不进日志、不自动续期。401/403 标记失效并可回退本机记录；网络故障不会把有效 Token 标失效。完成 HTTP 接收 Codex / Claude / Cursor / Grok / Copilot CLI / Antigravity。Manus 完成不走 HTTP：在设置里单独开启「接收完成提醒」后，由本机用已配置的 API Key 只读轮询官方任务 API（面板运行时检查，关闭后下次启动补查）；点击打开 manus.im 任务页。等待输入/授权尚未接入。

首页编辑模式下拖动卡片只交换位置，各自保留尺寸；靠近网格边界时向左或向上收，有冲突则按原尺寸顺序重排。补洞锁定交换双方，只允许其他卡片扩展；无法按原尺寸放下时提示「空间不够，无法交换」并保留原布局。

## 简化交互

- 只有全新安装会进入三步欢迎：学习唤出、选择首页组件、可选连接 NAS 或 AI。欢迎向导从当前平台默认布局开始，按用户勾选逐项设置组件；升级不改变已有布局。设置 → 显示 → 首页仅提供各组件的独立显隐开关，加入组件时保留原有自动让位规则，至少保留一个组件，录音中不可隐藏快录。
- NAS 卡默认只显示连接状态、一句说明和主操作。未配对的地址与配对码放在「连接设置」，配对后的迁移、回退、HTTP 等详情放在「故障处理」；本机备份还可从独立的「资料与备份」进入；暂时连不上时提供重试。省略协议时补 HTTPS；检测到 HTTPS 指向纯 HTTP 服务时仅纠正输入地址，再次操作仍需明文确认，不自动降级传送凭据。
- Cursor/Codex 的「获取并保存」由主动点击触发，只读本机登录并加密保存。其余手动 Token 收在「手动填写」，Grok 团队 ID 与 Manus 完成开关保留。状态只按实际成功的额度数据说明生效来源。
- AI 额度默认每家显示最短统计周期的剩余值，悬停、点击或键盘可展开窗口明细；迷你脚注显示瓶颈窗口及紧急状态摘要，可点击或按 Enter/空格查看完整详情，非迷你卡片的来源名保持单行，空间不足时优先使用 Claude / Antigrav 等短名，再按可用宽度缩字号或省略，悬停与无障碍标签保留完整名；环长和大数字使用最短窗口，颜色、紧急排序与过期判断使用所有窗口的最小剩余瓶颈；长周期偏低时由窗口条等级色和真实重置时间提示，未知时间不显示。用完时灰环、淡红底轨和数字划线，mini 用色点与单行摘要提示；小号/中号不重复主窗口条，大号保留实际窗口条，明细显示所有窗口并独立标色。失效显示居中红色虚线圈与叹号，底部仅留「失效 · 去设置」；迷你失效摘要直接打开设置。过期沿用原阈值，头部显示灰色时钟与真实数据年龄，环、数字与窗口条降至约 45% 透明度。Grok Bot 来自代码中的 Cursor Sand 接口，可使用本机登录或已保存 Cursor Token，不是 xAI Grok 余额。
- 随笔记始终编辑，保存后清空并收进顶栏「笔记」，可接着写下一条；快录提供「在录音中打开」。关闭工作区会隐藏对应顶栏 tab；关闭录音工作区也会隐藏快录入口。前三次唤出会提示胶囊操作。
- 覆盖确认先显示来源及增改删摘要，详情可展开；取消不写入。凭据读取、保存或清除失败统一显示可关闭的报错条，提供修复入口与复制脱敏诊断；报错条单独占位，内容区可滚动，避免遮挡底部控件；本机登录缺失或读取失败与登录过期分别提示。必填项等表单校验保留行内提示，摄像头以及布局空间不足等瞬时提示短暂显示；布局应用并保存成功后清除对应布局报错，取消、无变化或保存失败时保留。Windows 的「当前窗口」可内联开启原生能力，加载失败时保留可恢复提示；仍不绕过强制关闭开关。

## 设计原则

- **停在边上，展开才占一块桌面**：macOS 收起只留一颗胶囊，展开从你选的边长出来。窗口边界变更不使用系统动画，视觉动效留在渲染层，并尊重「减少动态效果」。
- **设备按需启用**：镜子只有主动点击才开摄像头，离开首页或收起时立刻释放。麦克风只在开始录音后使用，结束录音或退出应用时释放。
- **数据留在这台电脑**：待办、笔记、链接、录音元数据和工作区设置写在本地。可以更换数据文件夹，把工作区拷到另一台电脑。系统加密过的密钥不保证跨电脑迁移。
- **同步是附加项**：飞牛伴侣同步待办、笔记、链接、常用指令、剪贴板、AI 完成记录、录音、AI 配置和密钥。它不替换本机存储。首页布局不同步。
- **权限边界清晰**：链接抓取拒绝本机、内网和不安全重定向。窗口聚焦只接受最近一次扫描缓存里的窗口 ID。剪贴板跳过密码管理器标记为敏感的内容。

## 本机 AI 完成提醒

Pome Panel 只在 `127.0.0.1:43821` 监听通知，来源限 `codex`、`claude` 与 `cursor`，其余一律 404。提醒是一块不抢焦点的小窗。AI 完成与等待气泡同时只展示最新一条，新事件直接顶替旧 AI 气泡；待办到期提醒独立按顺序排队。可在「设置 → 本机与唤出」关闭顶部气泡提醒；关闭后仍写入 AI 完成收件箱与待处理列表，只是不再弹出顶部气泡。子代理结束和云端会话不会弹出。Windows 上点击提醒即关闭。

带倒计时的通知气泡在鼠标悬停时暂停，移开后从原剩余时间继续，不额外补时；即使已经接近消失，也不会把进度条重新拉长。

```bash
curl -X POST http://127.0.0.1:43821/notify/codex \
  -H 'Content-Type: application/json' \
  -d '{"title":"任务已完成","project":"my-project","task_id":"demo","event_id":"demo-completion-1"}'
```

在「设置 → AI」检测并接入可 hook 的完成来源（Codex、Claude Code、Cursor、Grok、Copilot CLI、Antigravity）；同一列表展示其余家的额度能力与归属说明。Grok 写入 `$GROK_HOME/hooks/pome-panel.json`（未设置时为 `~/.grok/hooks/pome-panel.json`）的 Stop / StopFailure；按会话与 `promptId` 区分轮次和重试，忽略子代理及退出会话事件。Grok 来源名与图标在完成气泡和收件箱中保留，点击沿用终端打开方式；完成历史参与 NAS 同步及统一的最新 100 条裁剪。确认浮层列出修改文件、Pome 钩子内容和同目录的 `.pome-backup-时间戳` 备份；确认后先校验备份再原子写入。配置损坏时拒绝修改，预览过期或文件被外部编辑后需要重新确认。仅增删 Pome 标记项，其他配置、钩子和缩进保留；Codex 的原 `notify` 被继续转发，断开后还原。Codex 接入后需重启工具。

通知与收件箱保留 completed / failed / awaiting / due 状态。标题跳过空泛的“已完成”首行，摘要最多保留 4096 字符，省略只发生在显示层，悬停可读完整摘要。Codex 原生会话名按精确 thread ID 只读本机会话索引或 SQLite 元数据，与完成摘要分开保存；不存在时不伪造。打开来源软件失败时保留气泡、暂停倒计时并显示原因，可重试或点 × 关闭。

优先用 Pome 自带 Electron 的 Node 运行时，脚本采用当前应用安装路径。每次启动检查接入路径，应用搬家后可点「修复」。Claude Code 使用 `hooks.Stop`，Cursor 使用官方 `hooks.json` v1 的 `hooks.stop` 与 `hooks.afterAgentResponse`，以 conversation_id 与 generation_id 关联摘要并去重。现有 stop-only 配置仍可接收通知；在设置中点「修复」可补上摘要钩子。原生 error 映射为失败，aborted 不作为成功提醒。摘要仅在本机私有目录缓存（读取有效期 10 分钟、最多 256 条、每条 4096 字符；后续写入清理过期项），stop 读取后移除；可用时也会有界读取 transcript_path。首次检测到未接入工具会提示；「以后再说」仅存本机并停止重复提示。

设置和首页不再显示「发送测试」。后端测试接口仍经过同一转发脚本和本机接收服务，不产生历史、未读或真实完成提醒。首页未接入、等待第一条、接入失效三个空状态分别引导接入、管理、修复。损坏收件箱仍使用独立的确认重建流程。

仓库提供 [Codex](../scripts/codex-notify.js)、[Claude Code](../scripts/claude-notify.js)、[Cursor](../scripts/cursor-notify.js)、[Grok](../scripts/grok-notify.js)、[Copilot CLI](../scripts/copilot-notify.js)、[Antigravity](../scripts/antigravity-notify.js) 转发脚本。Claude 云端会话（`CLAUDE_CODE_REMOTE=true`）不会转发；Grok 触发的 Claude/Cursor 共用钩子由 Grok 脚本接管。

Copilot CLI 使用 `$COPILOT_HOME/hooks/pome-panel.json`（默认 `~/.copilot/hooks/pome-panel.json`）的 `agentStop` 与不可恢复的模型/系统错误事件；退出会话、子代理及可恢复的工具错误不作为完成。按当前助手结果标识去重，缺少结果时使用带时间的事件身份。配置使用直接执行参数，避免 shell 转义。

Antigravity 使用 `~/.gemini/config/hooks.json` 中独立的 `pome-panel.Stop`，保留其他 hook；仅在后台任务全部结束且停止原因为模型结束时提示完成，系统错误或步数耗尽提示失败。会话与执行序号区分轮次。官方事件未提供回答正文，完成摘要暂使用默认标题；App/IDE 打开 Antigravity，CLI 打开终端。两家均保留“受限”标记，未声称覆盖 Copilot VS Code/云端或未验证的转录格式。其他 Stop hook 若要求继续运行，首版仍受门控事件时序限制。Grok Bot 完成接入保持未支持。Manus 完成见上文 API 轮询通道（partial）。

Manus 监听按账号保存分页检查点与待核验的结束事件；同账号更新 Key、断网和正常重启保留进度，主动关闭后再开启从新监听时段开始。新任务、活跃任务和旧任务分页扫描共用限流预算并公平调度，大量任务或长时间离线会增加发现延迟，不保证实时或任意离线时长完全补齐。完成记录与其他来源合计保留最新 100 条并同步 NAS；内部仅保留必要的去重控制信息，已确认投递的正文会从控制队列清除。标题、摘要和同步字段在落盘前过滤敏感凭据。Key 本身具有较广权限，面板仅调用读取接口，不替用户回答、授权或修改任务。

### AI 待操作提醒（开发版）

**范围**：完成提醒可接入 Codex / Claude / Cursor / Grok / Copilot CLI / Antigravity。额度按各家已接入的数据来源展示。等待输入/选择/授权目前主要覆盖 Claude（受限）；Codex、Cursor、Grok、Copilot CLI 与 Antigravity 尚未启用等待监听，不会用猜测或轮询冒充等待状态。

新的 v2 事件在同一回环接收地址上区分完成与等待输入、选择、授权。macOS 等待气泡采用 B 蓝色定稿（400×146，顶部 32px 黑区），Windows 为 384×114 顶部卡片。完成气泡保持原尺寸。等待摘要单行显示；敏感参数在落盘前隐藏，完整安全摘要在首页「AI 完成 → 待处理」列表查看。来源图标与状态独立。

等待没有倒计时；单条常驻，新 AI 完成或等待事件直接顶替旧 AI 气泡（包括悬停中的气泡），旧项不再自动轮换或回放。被顶替的等待请求仍保留在待处理列表，可手动重新弹出，不会据此判定已解决。待办到期提醒独立排队，按顺序逐条展示，不会被 AI 新事件覆盖；等待气泡遇到待办提醒时，未悬停情况下最多保留 8 秒后让出展示。气泡 `+N` 只统计接下来确实会展示的条目，不包含被顶替或隐藏的等待请求。悬停暂停当前倒计时，移开后继续原剩余时间。点击主体/按钮仅返回来源，× 只隐藏这次提醒，均不算已回答。来源的匹配解决、取消或继续事件撤销请求，不额外弹已回答。首页 AI 完成组件的「待处理 · N」入口在首页打开小列表，可返回来源、重新弹出旧提醒；重启后未确认的请求仍可返回来源核实。存储损坏时，同一入口提供备份并修复操作。首页组件被隐藏时，可先从「设置 → 显示 → 首页」恢复 AI 完成组件。Windows 原生能力关闭时提示「请返回来源软件」，点击仅隐藏，不加载 koffi。

Cursor MCP 需要 OAuth 时，可执行 `node scripts/cursor-mcp-auth-notify.js --service "Google Drive"` 发送一次 v2 授权提醒；授权成功后再执行同一命令并加上 `--resolved`，顶部气泡会自动收起。每次弹出与每次成功收起都有独立身份并去重；`--resolved` 只关闭该成功时刻及之前已打开的同服务请求，不会误关之后新开的授权。只进入本机待处理列表，不产生完成历史或未读。此脚本不自动完成授权；手动关闭气泡不代表授权成功。

等待状态只保存于本机 userData 下的 `ai-attention.json`，不进入完成历史、LocalStorage 或 NAS。身份包含来源、客户端 surface、会话、回合、请求；乱序解决事件留短期 tombstone。重启/断开后保留入口并标为需确认，不自动重弹或按超时宣布完成。存储损坏/外部修改会拒收，可从首页待处理入口确认后先备份原文件再重建。

Claude 的一键接入/修复会预览并追加专用观察 hook（PreToolUse、PostToolUse、PostToolUseFailure、Notification、UserPromptSubmit、Stop、SessionEnd），stdout 为空，不回答、不授权。旧 Stop-only 接入提示「等待提醒需补全」。AskUserQuestion 关联精确 tool-use ID；`idle_prompt` 不提醒；没有稳定请求 ID 的授权/表单仅在明确的继续或结束边界收敛，不用无关工具返回猜解决。授权 Notification 可能约 6 秒后触发。授权请求优先使用来源的请求/通知身份，否则每次 hook 调用生成独立观察 ID；同一观察在当前回合内的网络重投合并，新调用（包括同命令再次请求）分别记录。缺少原生 ID 时无法可靠区分来源重复触发与新请求，因此仍为 partial。批量撤销一次原子提交，隐藏请求不计入气泡 +N；固定 npm install 脱敏预览支持中英文前缀，完整命令和参数不会转发。当前缺少 Claude Code 实机验收，能力为 partial；Codex 桌面端与 Cursor IDE 的等待事件未验证，未启用 watcher/bridge，不承诺覆盖现有弹框。详情见 [事件方案](plans/2026-10-18-ai-notification-events.md) 和 [实施与验收记录](plans/2026-10-18-ai-attention-implementation.md)。

Codex 完成输出中，整条文本（可含一层 JSON 围栏）恰为 `{"suggestions":[]}` 或 `{"exclude":[]}` 时忽略；普通 JSON 与含 JSON 的自然语言结果保留。旧同形记录只在分页、总数、未读和最新条目的统一投影中隐藏，不批量删除。旧 notify 无已核实的用户意图证据，因此用户刻意要求输出该精确空数组对象时也可能命中此窄规则；未经验证的 `final:true` 不绕过过滤。

## Windows 上的几件事

全新安装首次打开首页时，日出日落默认显示，可用组件会重新排布并填满首页网格；未改动的旧 Windows 默认布局也会自动修复。首页还可开启「黄历」模块（迷你 / 小 / 中 / 大），用 `lunar-javascript` 离线计算公历农历、干支、节气、宜忌、冲煞、纳音、建除、值神、星宿、吉神、彭祖百忌与吉时，跨过零点或从睡眠唤醒后自动切到新一天。小、中、大号显示节气交节时刻，按计算结果取整到分钟并注明北京时间（UTC+8）；倒计时为日历天数，公历日期跟随电脑本地日期。大号吉时显示具体钟表时间段，区分早子（当天 00:00–00:59）与晚子（当天 23:00–23:59）；宜忌和吉时属于传统黄历参考。Mac 默认布局与用户自定义的组件显隐、尺寸和位置不变。两端的城市选择气泡会避开面板边界，搜索列表较长时在气泡内滚动，自定义位置表单保持可操作；收起面板后立即关闭，下次展开需手动点击位置按钮重新打开。

### 安装目录与桌面快捷方式

双击 `windows-x64-setup.exe` 进入安装向导，在「选择安装位置」中填写目录或点击「浏览」选择，例如 `D:\Apps\Pome Panel`。安装完成后，桌面和开始菜单会创建指向该目录主程序的 `Pome Panel` 快捷方式；手动重新安装会恢复缺失的桌面快捷方式。程序文件保存在所选目录，默认目录为 `%LOCALAPPDATA%\Programs\Pome Panel`。

### 通知钩子怎么配

优先使用设置页的一键接入，不依赖 PATH 中的 Node。默认应用目录为 `%LOCALAPPDATA%\Programs\Pome Panel`，接入器使用实际安装路径。本机配置分别位于 `%USERPROFILE%\.codex\config.toml`、`%USERPROFILE%\.claude\settings.json` 和 `%USERPROFILE%\.cursor\hooks.json`。Windows 通过随应用分发的 PowerShell 文件桥接设置 `ELECTRON_RUN_AS_NODE=1`，把通知 JSON 当数据传给脚本；不会把 JSON 拼进命令表达式。只有用户确认后才写工具配置。仍需 Windows 真机验证，不以 Mac 回归代替。

### 原生能力（实验功能，默认关闭）

「当前窗口」、剪贴板自动粘贴和「点击完成通知聚焦对应窗口」在 Windows 上依赖进程内的 Win32 调用。这三项默认关闭，在「设置 → Windows 原生能力 · 实验功能」里打开后立即生效，不需要重启。

打开后：首页出现「当前窗口」，列出当前虚拟桌面上的窗口（按前后顺序，排除工具窗口），点击即切换并还原最小化的窗口；点击剪贴条目会自动粘贴回刚才的窗口，只发送一次 Ctrl+V，不安装全局键盘钩子。目标窗口以管理员身份运行时，系统会静默拦掉模拟按键，所以面板会提前识别并提示手动粘贴；目标已关闭或中途被切走，则退化为「已复制」。

之所以默认关闭：安装包不签名，而「模拟按键」「枚举并切换其他进程的窗口」是安全软件的常见启发式特征。Windows Defender、火绒与 360 的首轮测试都无告警后，才会改成默认开启。排障时可以用环境变量 `POME_DISABLE_WIN_NATIVE=1` 启动，强制不加载原生模块。

### 第一次打开时的 SmartScreen

安装包没有代码签名，Windows 会弹出「Windows 已保护你的电脑」。点**更多信息 → 仍要运行**即可。安装包每次发新版都会重新触发这一步。安全软件报「未知发布者」或「新增开机启动项」时，同样是未签名导致的，可以在各自的信任列表里放行。

### 已知限制

- **不签名**：见上面的 SmartScreen 流程。
- **不跟随虚拟桌面**：切到别的虚拟桌面后面板不会跟过去，切回来即可。
- **没有汽水音乐**：控制汽水音乐依赖 macOS 的脚本接口，Windows 上这个组件永久隐藏。
- **原生能力默认关闭**：「当前窗口」、自动粘贴与通知点击聚焦要手动打开，见上面一节。
- **Windows arm64 未测试**：只发 x64 安装包。arm64 设备会在仿真下运行，随包的原生模块也是 x64 的，没有验证过。
- **胶囊只有 9px 高**：贴在工作区顶部，会盖住最大化浏览器标签栏最上面的一小条。任务栏放在屏幕顶部时胶囊落在任务栏下方；Win11 把窗口拖到屏幕顶部中央弹出的 Snap 布局条也会和它重叠。
- **剪贴板只复制**：没开原生能力时，点击条目是写回系统剪贴板，需要自己按 Ctrl+V 粘贴。

## 日出日落与当前天气

天气胶囊跟随日出日落模块的同一地点，仅显示当前状态与温度，大号额外显示湿度。mini 使用图标和温度，地点收为 pin；small 缩短天气名并省略长地名。现有倒计时、太阳弧线和天文时刻表保持独立。

天气数据由 [Open-Meteo](https://open-meteo.com/) 提供。没有后台轮询：面板收起时不请求，连续打开超过半小时也不主动更新；下次唤起且距该地点上次请求已满半小时，才请求 current 数据。失败不提示、不替换旧数据，半小时内不重复重试；从未成功时显示「天气 · --°」。缓存只保存在本机，不参与 NAS 同步。

「设置 → 本机与唤出 → 天气动态效果」默认开启，仅中/大号显示背景粒子。mini/small、面板收起、离开首页、应用不可见或系统启用减少动态效果时停止粒子；关闭开关不会隐藏天气文案。没有音效。雨雪雷风的运动规格和验收见 [天气实现说明](weather-implementation.md)。

## 工作台界面

待办顶部显示未完成与总数，添加分类位于右上角；原有分类、截止编辑和提醒规则不变。笔记左侧提供搜索与轻量索引，正文预览会隐藏与笔记标题完全相同的首行一级标题，编辑和存储的 Markdown 原文不变。

密钥页默认展示资料库，使用「新增密钥」打开填写弹窗。取消、Esc、点击遮罩、切换页面或收起面板会关闭弹窗并重新遮蔽密码；未保存输入仅在本次会话中保留。保存成功关闭表单，失败保留草稿并提供错误反馈。

录音播放器可播放/暂停、拖动进度、调节音量或静音，并选择播放速度。切页或收起时暂停播放，切换录音释放旧播放器资源。设置首屏优先展示 AI 与本机唤出，录音转写、镜子封面、显示和 NAS 仍可在对应栏内滚动找到。


## 操作与地区偏好

- 首页内容全部保留。窄窗口采用纵向滚动；编辑布局需加宽窗口，尺寸与摆放记录不会被临时窄屏覆盖。额度空态的说明可滚动，「去设置」按钮独立保留在卡片内。
- 待办颜色代表分类，百分比代表截止前剩余时间。日期与快捷键浮层内按 Esc 先取消当前操作；日期仅明确选择才生效。
- 剪贴板支持文字搜索。清空确认作用于全部历史，包含收藏，不受当前搜索或类型筛选影响；确认期间内容变化则取消这次清空。收藏保留至手动删除，普通记录保留最近 100 条。
- 链接支持标题、网址和分组搜索，以及移至已有分组。无法读取网页标题时保留域名。新增笔记后的提示可进入笔记库，详情有独立重命名入口；密钥列表提供编辑与复制动作。只有一段 API Token 时，将项目名称填入账号、Token 填入密码。
- 录音无需配置 API；转写和智能命名分别选配。暂停时状态明确显示暂停，停止后保存并释放麦克风。播放器优先采用媒体时长，WebM 尚未报告有效时长时回退到保存的录音时长。
- 识别语言、转写服务区域与界面语言分别保存。切换界面语言不会改变已有识别配置。创建 Key 的帮助随北京/新加坡区域选择切换，账号、Key 与服务地址须匹配区域。
- 「设置 → 本机设置」可选择摄氏/华氏以及跟随系统/减少动态；仅影响本机显示。减少动态会抑制位移、装饰动画和天气粒子，保留状态文字与计时。黄历保留传统原文，公历星期随界面语言显示；说明区分本机日历、节气北京时间及所选天气城市的时区。
- 首次连接 NAS：先安装并打开 fnOS 的 Pome 伴侣，生成配对码，再填写伴侣提供的同步服务完整地址。地址或六位配对码格式错误在字段旁说明；真实连接失败继续使用持续错误条与诊断详情。
- 「设置 → 资料与备份」无需配对即可导出或恢复。包含普通工作区内容和媒体，不包含密码、AI Key、设备令牌与首页布局；恢复仍先校验、预览并创建当前资料快照。


### 随笔记与笔记编辑

首页随笔记始终作为可恢复的编辑草稿。点击「保存」后，内容收进笔记库并从首页清空；整个随笔记组件保留背景、标题、按钮和正文，先收窄成弯曲漏斗，再吸入顶栏「笔记」；原位恢复空白组件。动画期间可继续写下一条，减少动态效果时改为轻量反馈。笔记库点击正文即可编辑，点击「保存」或按 Ctrl/Cmd+S 回到预览，保持当前阅读位置；后台自动保存不退出编辑。链接点击和拖选正文保持原用途，保存失败保留内容并在错误栏提供重试。


### 当前窗口

macOS 的「当前窗口」按系统辅助功能暴露的标准窗口枚举与聚焦，保留真实同名窗口，不按系统图形表的序号切换。点击已关闭或无法聚焦的窗口会提示刷新，不自动改开另一个窗口；最小化窗口可恢复。窗口名为主、应用名为辅，窄组件使用可滚动单列，全部条目均可滚动访问。长按拖出可单独隐藏窗口，点击「恢复」找回；旧的隐藏偏好继续保留。此功能使用辅助功能权限，不再为读取窗口标题申请屏幕录制权限。

窗口发现覆盖所有显示器坐标，并补充其他桌面及全屏空间中被 AX 普通清单省略的窗口。扫描有时间上限，大型清单可能随刷新逐步补全；macOS 兼容接口不可用时回退到系统直接暴露的窗口，不为补全申请额外屏幕录制权限。切换时同时验证窗口身份和系统编号。
