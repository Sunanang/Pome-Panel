# 按需读取凭据与钥匙串说明

分支 `dev`，基线 `33dc6ad`。保留系统加密，不改凭据格式，不迁移或清除用户的密文。

## 用户看到的行为

- 每次启动，需凭据的额度读取默认暂停；「设置 → AI → 读取额度 / 重试授权」为本次运行启用读取。额度卡片的待启用入口直接定位到说明与按钮。Codex 无需凭据的本地记录仍可读取。
- 主动保存 Token 仅启用该来源，不顺带开启其他工具的凭据读取；Cursor 的 Token 同时供 Cursor 与 Grok Bot 使用。
- Token、转写与命名配置展示仅检查是否存在已保存配置，不解密；“已配置”不代表已经验证可用。打开密钥页才读取现有密钥库，空库不访问系统安全存储。
- 录音、AI 命名、保存密钥或 API Key 等实际操作仍需要加解密；拒绝时保留原密文，普通录音不依赖转写 Key。录音配置弹窗与密钥页有对应说明。
- 本次运行内，对失败的自动额度凭据读取不反复请求；用户主动重试才再次读取。Claude 优先使用有效凭据文件；需要钥匙串时异步读取并共享请求，在本次运行缓存结果。切换 Claude/GitHub CLI 账号或凭据失效后，可主动重读。
- 已启用的 NAS 自动同步、Manus 完成提醒仍按原规则在启动时访问所需凭据。系统钥匙串锁定、权限撤销或应用签名变化仍可能触发提示，不能保证系统完全不弹窗。

界面明确告知：凭据用于对应服务，不写日志；系统授权由 macOS 处理，Pome 不接收 Mac 登录密码、不遍历整个钥匙串；拒绝不影响本机完成 HTTP 事件接收。Manus 属于使用凭据访问官方任务 API 的独立后台功能，不混同于本机 HTTP 监听。

## 实现与安全边界

- Electron `safeStorage` 延迟解析；被动状态不调用可用性探测，避免仅检查状态也初始化系统加密。内部状态中 `secureStorage: null` 表示尚未检查，实际写入仍验证并强制加密。
- 未配对 NAS 状态采用生产侧显式启用的 `lazyStatus`，无凭据文件时不探测系统安全存储；现有绑定与实际保存仍走原加密校验。
- 额度启用状态只在进程内，不写 LocalStorage、工作区或 NAS。没有明文回退，没有导出本机系统加密密钥。
- 失败记录留在内存；没有额外长期缓存 Pome 已解密的 Token 明文。Cursor 使用现有内存密钥缓存，Claude/GitHub CLI 的本次读取结果可通过明确操作重试。
- 新的启用 IPC 验证主面板发送方，普通刷新 `force` 不代表用户同意读取凭据。
